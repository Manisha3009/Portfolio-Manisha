MANISHA A — CINEMATIC PORTFOLIO (PHOTO-MATCH EDITION)
==================================================
THEME
  Midnight navy / sapphire blue / electric ice blue, with subtle warm gold light
  Matches the generated professional portrait on the homepage

START
  Open index.html directly in Chrome, Edge, or Firefox. Internet is only
  needed to load the Google Fonts and follow outbound links.

DEPLOY ON VERCEL
  Upload the contents of this folder to a GitHub repository, then import
  the repository to Vercel as a static site (no framework or build command).
  Alternatively, deploy this folder using Vercel CLI.

FOLDERS
  index.html           All portfolio content
  style.css            Original site layout styles
  cinematic.css        New portrait-matched theme, light effects and animations
  script.js            Navigation, scroll reveals, 3D hover interactions
  assets/profile.jpg   Updated blue-lit professional portrait
  assets/profile-original.jpg  Original profile photograph backup
  assets/Manisha_A_Resume.pdf   Resume button attachment

MOBILE
  Layout is responsive; animations respect system reduced-motion preferences.
